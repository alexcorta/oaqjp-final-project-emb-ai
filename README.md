# Emotion Detection Application

AI-based web application developed with Python, Watson NLP, and Flask.

The application analyzes customer feedback and determines the following emotion scores:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the submitted text.

## Main components

- `EmotionDetection/emotion_detection.py`: Watson NLP emotion analysis
- `EmotionDetection/__init__.py`: Python package definition
- `test_emotion_detection.py`: Unit tests
- `server.py`: Flask web application
- `templates/index.html`: Web interface
